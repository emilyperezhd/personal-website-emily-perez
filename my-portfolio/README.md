# Personal Portfolio Website

🔗 **Live Site:** https://personal-website-emily-perez.vercel.app

This repository contains the source code for my personal portfolio website. The site serves as a central place to learn more about me, explore my projects, review my experience, and see my technical skill set.

## Overview

I’m a Computer Science (Co-op) student at the University of Guelph with a Business minor. This portfolio highlights:
- My academic and professional experience
- Featured technical projects with detailed breakdowns
- A comprehensive overview of my technical skills
- Ways to get in touch with me

The site is designed to be clean, responsive, and easy to navigate, with a focus on clarity and usability.

## Features

- Modern, responsive UI built with React and Tailwind CSS  
- Project showcase with interactive modals and screenshots  
- Experience section highlighting internships and leadership roles  
- Skills overview, including a full technical skills modal  
- Contact section with links to email, GitHub, and LinkedIn  
- Smooth scrolling and polished visual design  

## Tech Stack

- **Frontend:** React, JavaScript, Tailwind CSS  
- **Build Tool:** Vite  
- **Deployment:** Vercel
